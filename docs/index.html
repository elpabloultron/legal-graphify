Razonamiento Dogmático

Los 6 Pilares de Inferencia Relacional

LegalGraphify trasciende el RAG vectorial tradicional resolviendo la estructura jerárquica y deductiva propia del derecho continental.

1. SUBGRAFOS [query_legal_subgraph]

Extracción de Subgrafos Locales

Aísla la institución consultada y su vecindario relacional a $N$ saltos. Genera un bloque YAML hiper-denso con artículos BCN concordantes, tratadistas y fallos rectores de la Excma. Corte Suprema.

$ legal-graphify query "simulacion" --depth 2
2. CAMINOS [trace_legal_path]

Trazado Deductivo Multiruta

Encuentra la ruta dogmática más corta entre dos instituciones o leyes aparentemente inconexas, deduciendo la subsunción procesal paso a paso sin lagunas argumentativas.

$ legal-graphify path "simulacion" "inoponibilidad"
3. EXPLICACIÓN [explain_legal_entity]

Ficha Dogmática Integral 360°

Genera un informe analítico completo: definición canónica unificada, requisitos de existencia y validez, operativa procesal forense, vías de impugnación y centralidad en la red.

$ legal-graphify explain "objeto_ilicito"
4. IMPACTO [analyze_statutory_impact]

Análisis de Radio de Afectación

Simula las consecuencias sistémicas de reformas legales o cambios de jurisprudencia. Identifica instituciones directamente afectadas (Grado 1) y en cascada (Grado 2).

$ legal-graphify affected "Art. 1464 CC"
5. PILARES [get_god_nodes]

Detección de Pilares Estructurales

Aplica algoritmos de PageRank y centralidad de intermediación para aislar los conceptos jurídicos axiales que sostienen el mayor número de dependencias legales.

$ legal-graphify god-nodes --top 10
6. DOC2MARKDOWN [ingest_document_to_markdown]

Ingesta Autónoma & Normalización RAE

Convierte documentos (.pdf, .docx, .txt, .md) a Markdown canónico token-optimizado conforme a las normas ortotipográficas RAE/ASALE y citas BCN/CS, asimilando nuevos nodos al grafo en caliente.

$ legal-graphify ingest "tratado.pdf" --update-graph

Desarrollo & Agentes

Integración Rápida: CLI, Python & MCP

Utiliza LegalGraphify como biblioteca de Python, herramienta de terminal o servidor FastMCP. 

# Instalar LegalGraphify localmente:
$ pip install legal-graphify

# Consultar subgrafo con 2 saltos de profundidad:
$ legal-graphify query "simulacion" --depth 2

# Trazar camino deductivo mínimo:
$ legal-graphify path "simulacion" "inoponibilidad"

# Ingestar y asimilar documento con normalización RAE:
$ legal-graphify ingest "tratado.pdf" --output "doctrina/imprevision.md" --update-graph
